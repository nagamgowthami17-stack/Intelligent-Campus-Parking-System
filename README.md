
# Intelligent Campus Parking Allocation System

## 1. Introduction
The Intelligent Campus Parking Allocation System is a project designed to allocate limited parking spaces to vehicles efficiently.

It uses different algorithm techniques to select vehicles based on the available parking capacity.

## 2. Objectives
- Allocate parking spaces efficiently.
- Reduce parking space wastage.
- Implement and understand different algorithms.
- Compare the results of different approaches.

## 3. Technologies Used
- C Programming
- HTML
- CSS
- JavaScript
- Docker

## 4. Algorithms Implemented
1. Brute Force
2. Backtracking
3. Greedy Algorithm
4. Dynamic Programming

## 5. Project Structure

Campus_Parking_DAA/
- backend/main.c
- frontend/index.html
- frontend/style.css
- frontend/script.js
- Dockerfile
- README.md

## 6. How to Run the Project

### Backend (C Program)

Open the terminal in the project folder.

Compile the program:

```bash
gcc backend/main.c -o parking
```

Run the program on Windows:

```powershell
.\parking.exe
```

### Frontend

Open the frontend folder and run index.html using VS Code Live Server.

## 7. Expected Output
The system displays the vehicles selected by each algorithm, the total parking space used, the number of vehicles accommodated, and the remaining parking capacity.

## 8. Future Enhancements
